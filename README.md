# Ashfall: Black Meridian

An original round-based 3D first-person zombie survival game built with Unity 6.

> This project is inspired by the pacing and survival-loop conventions of classic round-based zombie shooters, but uses original names, rules, art direction, code, and assets.

## Status

In active development as a playable vertical slice.

## Development

- Unity: `6000.5.7f1`
- Blender: `5.2 LTS` for procedural source assets
- Target: Windows/Linux desktop with keyboard/mouse and gamepad support

See `Docs/` for the game design and `Tools/Blender/` for the asset-generation pipeline.
